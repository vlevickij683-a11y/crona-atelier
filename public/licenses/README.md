# Asset sources
- Translation icon: Lucide Languages, https://lucide.dev/icons/languages — ISC (lucide.txt).
- Theme icons: Lucide Sun and Moon, https://lucide.dev/icons/sun and https://lucide.dev/icons/moon — ISC (lucide.txt).
- Country flag miniatures: https://github.com/lipis/flag-icons — MIT (flag-icons.txt). GB for English, RU for Russian, NO for Norwegian Bokmål.
- SVG assets are stored locally. No runtime calls to icon services.
- Storefront icons (sliders-horizontal, heart, x, arrow-up-right) are from Lucide and use the same ISC license.
- The six catalog images are AI-generated assets for this demo. Prompt notes: docs/catalog-images.md.
